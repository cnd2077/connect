Подключение VPN

Два шага: установите приложение INCY и нажмите «Подключить».

Ссылка повреждена. Вернитесь в бота и нажмите кнопку «Подключить» ещё раз.
1. Установите INCY
🍏 iPhone / iPad 🤖 Android / TV 🪟 Windows 🍎 macOS / 🐧 Linux
Уже установлено — переходите к шагу 2. Для Mac на M1–M4 берите файл macos-arm64.dmg, для старых — macos-intel.dmg.
2. Добавьте подписку
📲 Подключить в INCY Скопировано. В INCY нажмите «+» → «Импорт из буфера» / «Добавить подписку». Открыть в Happ
3. Включите

Выберите ⚡ Авто и нажмите кнопку подключения. Телефон спросит разрешение на VPN — разрешите.
