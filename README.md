# Сайт сервиса

Сайт собирается GitHub Pages автоматически: поменяли файл → через 1–2 минуты изменения на сайте.
Адрес: https://cnd2077.github.io/connect/

## Как поменять текст

1. Откройте нужный файл на github.com и нажмите ✏️ (Edit).
2. Поправьте текст и нажмите **Commit changes**.

| Что | Файл |
|---|---|
| Инструкция | `help.md` |
| Частые вопросы | `faq.md` |
| Главная страница | `index.html` (обычный HTML, тексты между тегами) |
| Пункты меню, адрес сервера | `_config.yml` |
| Кнопки скачивания INCY | `_includes/downloads.html` |
| Цвета и оформление | `assets/site.css` |

Файлы `.md` — это Markdown: `## Заголовок`, `**жирный**`, `- пункт списка`, `[текст ссылки](адрес)`.

## Как добавить новую страницу

Создайте файл, например `prices.md`:

```
---
layout: default
title: Цены
permalink: /prices/
---

Текст страницы…
```

Чтобы она появилась в меню, добавьте пункт в `menu` в `_config.yml`.

## Что не трогать без необходимости

- `cabinet/`, `add/`, `assets/*.js` — покупка, кабинет и подключение (работают с ботом).
- Тарифы, соглашение и политика берутся из бота — меняются там, а не здесь.
- Если сломалась сборка, на сайте остаётся прошлая рабочая версия; ошибка видна во вкладке **Actions**.
